# Original reference documents

English | [Français](README.fr.md)

This directory contains all eighteen supplied original specification PDFs,
preserving their filenames and bytes. Their structured catalogues record source
identities, SHA-256 fingerprints, physical pages and implementation coverage:

- [ISO 32000-1:2008](../iso32000-1/metadata.json).
- [Adobe supplement](../adobe-supplement-iso32000/metadata.json).
- [Archival Adobe references](../adobe-references/metadata.json).
- [ISO 32000-2:2020 EC3](../iso32000-2-2020/metadata.json).
- [PDF 2.0 companion bundle](../iso32000-2-bundle/README.md).

Both supplied copies of ISO 32000-2 are retained separately. The bundle records
its [PDF Association provenance](https://www.pdfa.org/sponsored-standards/).
These originals are excluded from Composer archives. Executable PDF test
fixtures are maintained separately under `tests/Fixtures/`.
