# Documents de référence originaux

[English](README.md) | Français

Ce dossier réunit les dix-huit PDF de spécification originaux fournis au projet,
avec leurs noms et octets d’origine. Leurs catalogues structurés consignent
identité, empreintes SHA-256, pages physiques et couverture d’implémentation :

- [ISO 32000-1:2008](../iso32000-1/metadata.json).
- [Supplément Adobe](../adobe-supplement-iso32000/metadata.json).
- [Références Adobe archivées](../adobe-references/metadata.json).
- [ISO 32000-2:2020 EC3](../iso32000-2-2020/metadata.json).
- [Bundle complémentaire PDF 2.0](../iso32000-2-bundle/README.fr.md).

Les deux copies fournies d’ISO 32000-2 sont conservées séparément. Le bundle
consigne sa [provenance PDF Association](https://www.pdfa.org/sponsored-standards/).
Ces originaux sont exclus des archives Composer. Les PDF exécutables des tests
restent classés séparément sous `tests/Fixtures/`.
