# Frozen Unicode 3.2 SASLprep data

English | [Français](README.fr.md)

RFC 4013 uses RFC 3454's Unicode **3.2.0** character tables and normalization. The Adobe supplement requires this exact profile before truncating a revision-5 password to 127 UTF-8 bytes. The library's `Unicode32SaslprepData` is an immutable generated PHP object; production code does not load JSON, depend on ICU, or use the host's current Unicode version.

`unicode-3.2-saslprep.json` is the equivalent maintainer data, generated by `tools/build_saslprep_tables.py` from Python's documented `unicodedata.ucd_3_2_0` normalization database and the explicit character ranges in retained `rfc3454.txt`. Character classification does not depend on the installed Python `stringprep` implementation. The generator preserves the historical normalization corrections by using the frozen database's `normalize('NFKD', ...)` results. Algorithmic Hangul syllables are always excluded from the tables because the PHP normalizer handles them directly; this keeps output identical across Python releases that expose those decompositions differently. `python tools/build_saslprep_tables.py --check` reproduces and compares both the JSON and PHP data.

Sources: [RFC 4013](https://www.rfc-editor.org/rfc/rfc4013), [RFC 3454](https://www.rfc-editor.org/rfc/rfc3454), [Python Unicode database documentation](https://docs.python.org/3/library/unicodedata.html), [Python stringprep documentation](https://docs.python.org/3/library/stringprep.html), and [Unicode's data licence](https://www.unicode.org/license.txt).

The derived Unicode data retain the [Unicode licence](UNICODE-LICENSE.txt). The retained RFC preserves its original copyright and permission notices. PHP implementation and test code remain under this project's MIT licence. `tools/validate_adobe_encryption.py` independently parses the RFC's tables and compares the SASLprep implementation with 24,744 deterministic cases, including every Hangul syllable, normalization, mappings, table boundaries, prohibitions, unassigned characters and BIDI.
